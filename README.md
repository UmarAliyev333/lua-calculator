# Console Calculator in Lua

My very first programming project. This is a CLI (Command Line Interface) calculator written in Lua after two weeks of studying the basics of programming.

## 🚀 Features
- **Four basic operations:** Addition, Subtraction, Multiplication, and Division.
- **Advanced math operations:** Modulo (`%`) and Exponentiation (`^`).
- **Input Validation:** Built-in protection against invalid inputs (`nil` checking) to prevent crashes.
- **Interactive UI:** Engaged console responses based on user input.

## 🛠️ Concepts Learned
- Variables and Data Types (`local`/`global`, strings, numbers, booleans, nil).
- Conditional statements (`if`, `elseif`, `else`).
- Type conversion (`tonumber`).
- User input handling (`io.read`).

*Developed as part of my preparation journey for the IT faculty at ADA University.*
